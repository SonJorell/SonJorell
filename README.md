## 📘 EduCom Web

### School Management & Communication Platform

Sistema desarrollado para modernizar la comunicación y gestión escolar, centralizando información y proporcionando diferentes experiencias según el rol del usuario.

Incluye autenticación segura, gestión de roles, notificaciones, confirmación de lectura, dashboards administrativos y auditoría de acciones.

**Architecture**

`Vue 3` → `Express.js` → `Prisma` → `MySQL`

**Technologies**

`Vue.js` `Node.js` `Express.js` `MySQL` `Prisma` `JWT` `Bcrypt` `TailwindCSS`

**Highlights**

- 🔐 Autenticación y autorización mediante JWT
- 👥 Sistema de roles y permisos
- 📡 Comunicación y notificaciones
- 📊 Dashboards administrativos
- 📝 Registro de acciones y auditoría
- 🛡️ Protección de credenciales mediante Bcrypt
