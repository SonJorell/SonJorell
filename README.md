## 👨‍💻 Sobre mí

Soy **Jorell Inostroza**, estudiante de **Ingeniería en Informática** en Arica, Chile. Me gusta transformar necesidades reales en software que funcione: plataformas educativas que operan sin internet, apps Android con NFC, modelos de Machine Learning, sistemas IoT con ESP32 y hasta juegos web.

- 🔭 Últimamente: **EduPlataforma**, una PWA offline-first para colegios, y **Mugen Family**, un juego de peleas 2D en Phaser
- 🌱 Profundizando en **TypeScript, arquitectura backend y Machine Learning**
- 🤝 Abierto a **prácticas profesionales, proyectos freelance y colaboraciones**
- 💬 Pregúntame sobre **React, Vue, Express + Prisma, FastAPI o Supabase**
